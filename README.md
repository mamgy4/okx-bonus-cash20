### Maker e taker: qual é a diferença?

A diferença não depende apenas de escolher uma ordem limitada ou uma ordem a mercado.

Uma ordem a mercado costuma ser executada imediatamente e, por isso, normalmente recebe a taxa taker. Já uma ordem limitada pode ser maker ou taker. Se ela for executada imediatamente contra uma ordem existente, será tratada como taker. Se entrar no livro e for preenchida depois, poderá ser classificada como maker.

Esse detalhe importa quando você tenta cumprir uma tarefa de volume para receber uma recompensa. Negociar várias vezes apenas para atingir o requisito pode gerar taxas, spread e risco de variação de preço. O bônus não deve ser avaliado sem considerar o custo para cumprir a campanha.

Para quem quer entender melhor o custo de uma operação, o livro de ordens costuma mostrar a cobrança de forma mais clara. Mesmo assim, é preciso observar:
